My Learning Plan

I will improve my web development skills by following a simple plan and practising consistently.

  1. Review HTML structure, semantic elements, links, images, and forms.
  2. Practise CSS selectors, the box model, colours, spacing, and typography.
  3. Build a responsive page, test it at phone width, and fix layout problems.
  4. Validate my HTML and ask a classmate to test the links and media players.
