# My ICT251 Activity 3 Website

My name is Samson K. Mbale. This is my personal website project.

## Files
- `index.html` contains the website.
- `css/styles.css` makes the website look better.
- `js/script.js` adds four simple features.
- `images` contains my Chelsea photos.
- `videos` contains the video and audio.

## Four JavaScript features
1. Contact form checks the details and shows a preview.
2. Previous and Next buttons change the photo.
3. A button changes light mode to dark mode.
4. A button shows or hides project details.

## How to test
Open this folder in VS Code. Open `index.html` with Live Server. Try all four features and check the website on a narrow screen.

The contact form is only a demonstration. It does not send a message.

## How to publish
Upload the files inside this folder to GitHub. Keep `index.html` at the top level. Replace the GitHub link in the website footer with your own repository link.

On Render, create a Static Site using your GitHub repository:
- Root Directory: leave blank
- Build Command: `echo "No build required"`
- Publish Directory: `.`
- Auto Deploy: on

After publishing, open the public Render link and check the website again.
